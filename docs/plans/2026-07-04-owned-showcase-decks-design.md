# 自有案例库替换设计

## 目标

将官网案例区现有 21 套案例全部替换为 PPT Master 自主生成的演示文稿。案例之间不统一视觉语言，而是通过明显不同的主题、版式、配色、信息密度和图形表达，展示生成系统的覆盖能力。

## 内容与设计原则

- 所有标题、正文、数据表达、图示结构和讲稿重新创作。
- 不复刻网上模板，不沿用旧案例的主题、人物、品牌和叙事。
- 每套至少包含封面、背景、核心框架、数据或图表、流程或时间线、案例页面、结论。
- 21 套分别使用不同的主色、字体气质、页面节奏和信息密度。
- 图表数据用于能力展示时明确为“演示数据”，避免被误解为真实商业结论。
- 首页仅展示生成完成且通过 SVG 质量检查的案例。

## 网站接入

- 用新项目重建 `examples/examples.json`。
- 每个案例的 `folder` 指向自有项目 `svg_final/`。
- 案例统计由项目清单自动计算，避免手工页数漂移。
- 页面在 HTTP 环境读取 JSON；在 `file://` 环境显示明确的启动提示和内嵌基础信息，不出现空白案例区。
- 桌面端验证筛选、封面、详情页和弹窗；移动端验证单列卡片、标题换行和触控目标。
